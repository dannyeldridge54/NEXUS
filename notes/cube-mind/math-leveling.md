# Cube Mind Notes — Math Leveling

## Pipeline

VEDIC NUMBER → CIRCLE DIVISION → POLYGON → RATIO → FREQUENCY → NOTE

| Stage | Meaning |
|-------|---------|
| Vedic number | Base number (e.g. digital root / mod 9 reduction) |
| Circle division | Divide the circle (360°) into N equal parts |
| Polygon | Connect the N points to form a regular N-gon |
| Ratio | Derive an interval ratio from the polygon (e.g. N:M of two divisions) |
| Frequency | Multiply the base frequency by the ratio |
| Note | Map the frequency to the nearest pitch |
